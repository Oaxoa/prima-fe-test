# Button

A button with a text label, an optional badge and an optional selected state. It's also the
building block of `Tabs.Tab`.

<Canvas of={Stories.Pill} />

```tsx
<Button text="Inbox" badgeLabel="3" badgeA11yLabel="3 unread" onClick={openInbox} />
```

## Variants

- **`pill`** (default): a rounded button with a border. When selected, it's filled with the
  inverse colour.

<Canvas of={Stories.PillSelected} />

- **`underline`**: text only. When selected, a bar is shown under the label. On hover the bar
  grows in.

<Canvas of={Stories.UnderlineSelected} />

## Badge

Set `badgeLabel` to show a `Badge` next to the label, and `badgeVariant` to pick its colour.
The badge text becomes part of the button's accessible name ("Inbox 3"). When the label alone
has no meaning, add `badgeA11yLabel` to give screen readers more context: the button is then
read as "Inbox 3 unread".

<Canvas of={Stories.PillBadge} />

## Selected state

`selected` shows the button as selected. Its meaning for assistive technology depends on how
the button is used:

- **Plain button** (no `role`): `selected` makes it a toggle button, exposed as `aria-pressed`.
  Without `selected`, there's no `aria-pressed` at all: it's a normal action button.
- **With a `role`** (as in `Tabs.Tab`, which passes `role="tab"`): no `aria-pressed` is set, and
  the caller adds the attribute that fits the role (`aria-selected` for tabs).

## Props

<Controls />

Any other `button` attribute (`aria-*`, `title`, `disabled`, …) is passed through.

## Accessibility

- It's a native `<button type="button">`: it works with mouse, touch and keyboard (`Enter` /
  `Space`), and it never submits an enclosing form by accident.
- Its accessible name is the `text`, plus the badge text (or `badgeA11yLabel`).
- It contains only inline elements, so the HTML is valid inside a `<button>`.
- The focus ring is shown only on keyboard focus (`:focus-visible`). It fades and moves outward
  as it appears. In Windows High Contrast mode the always-present transparent outline is turned
  into a visible one.
- With `prefers-reduced-motion: reduce`, all transitions are off, including the focus ring and
  the underline bar.
